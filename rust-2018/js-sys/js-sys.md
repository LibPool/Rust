# js-sys

> 标签: Rust

## 简介

Bindings for all JS global objects and functions in all JS environments like
Node.js and browsers, built on `#[wasm_bindgen]` using the `wasm-bindgen` crate.

## 官网

- 官网：https://wasm-bindgen.github.io/wasm-bindgen/
- crates.io 页面：https://crates.io/crates/js-sys
- 文档：https://docs.rs/js-sys
- 源码仓库：https://github.com/wasm-bindgen/wasm-bindgen/tree/master/crates/js-sys
