# dotslash

> 标签: Rust

## 简介

Command-line tool to facilitate fetching an executable, caching it, and then running it.

## 官网

- 官网：https://dotslash-cli.com
- crates.io 页面：https://crates.io/crates/dotslash
- 源码仓库：https://github.com/facebook/dotslash
