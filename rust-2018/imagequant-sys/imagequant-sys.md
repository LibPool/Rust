# imagequant-sys

> 标签: Rust

## 简介

Convert 24/32-bit images to 8-bit palette with alpha channel.
C API/FFI libimagequant that powers pngquant lossy PNG compressor.

Dual-licensed like pngquant. See https://pngquant.org for details.
