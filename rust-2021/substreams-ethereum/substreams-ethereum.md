# substreams-ethereum

> 标签: Rust

## 简介

Substreams development kit for Ethereum chains, contains Firehose Block model and helpers as well as utilities for Ethereum ABI encoding/decoding.

## 官网

- 官网：https://substreams.streamingfast.io/
