# mcf

> 标签: Rust

## 简介

Pure Rust implementation of the Modular Crypt Format (MCF) which is used to store password hashes
in the form `${id}$...`

## 官网

- crates.io 页面：https://crates.io/crates/mcf
- 源码仓库：https://github.com/RustCrypto/formats
