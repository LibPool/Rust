# serde_json_any_key

> 标签: Rust

## 简介

Workaround for "key must be a string" error with serde_json. De/serialize any HashMap<K,V>, Vec<K,V>, Iter<(&K,&V)>, or Iter<&(K,V)> as a JSON map.
