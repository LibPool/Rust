# precis-profiles

> 标签: Rust

## 简介

Implementation of the PRECIS Framework: Preparation, Enforcement,
and Comparison of Internationalized Strings Representing
Usernames and Passwords as defined in rfc8265; and Nicknames as
defined in rfc8266.
