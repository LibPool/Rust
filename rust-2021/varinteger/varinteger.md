# varinteger

> 标签: Rust

## 简介

Rust module for encoding/decoding varints that doesn't do any IO. Inspired by the Node.js varint module

## 官网

- crates.io 页面：https://crates.io/crates/varinteger
- 源码仓库：https://github.com/mafintosh/varinteger-rs
