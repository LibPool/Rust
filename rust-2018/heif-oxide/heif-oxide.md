# heif-oxide

> 标签: Rust

## 简介

Pure-Rust HEIF/HEIC still-image decoder (ISOBMFF container + HEVC via rust_h265). Decodes iPhone photos — grid tiles, 10-bit, Display P3 — with no C dependencies.
