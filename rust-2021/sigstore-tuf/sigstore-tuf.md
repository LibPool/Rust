# sigstore-tuf

> 标签: Rust

## 简介

A pure-Rust implementation of The Update Framework (TUF), aligned with Sigstore and interoperable with tuf-on-ci / securesystemslib repositories (e.g. GitHub's)

- crates.io 页面：https://crates.io/crates/sigstore-tuf
