# argon2

> 标签: Rust

## 简介

Pure Rust implementation of the Argon2 password hashing function with support
for the Argon2d, Argon2i, and Argon2id algorithmic variants

## 官网

- 官网：https://github.com/RustCrypto/password-hashes/tree/master/argon2

- 文档：https://docs.rs/argon2
- 源码仓库：https://github.com/RustCrypto/password-hashes
