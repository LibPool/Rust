# tfhe

> 标签: Rust

## 简介

TFHE-rs is a fully homomorphic encryption (FHE) library that implements Zama's variant of TFHE.

## 官网

- 官网：https://zama.org/
- crates.io 页面：https://crates.io/crates/tfhe
- 文档：https://docs.zama.org/tfhe-rs
- 源码仓库：https://github.com/zama-ai/tfhe-rs
