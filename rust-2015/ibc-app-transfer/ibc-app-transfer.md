# ibc-app-transfer

> 标签: Rust

## 简介

Maintained by `ibc-rs`, contains the implementation of the ICS-20 Fungible Token Transfer
    application logic and re-exports essential data structures and domain types from
    `ibc-app-transfer-types` crate.
