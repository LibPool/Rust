# rltk

> 标签: Rust

## 简介

A CP437/ASCII terminal library and helpers to make creating roguelike games in Rust easy. Similar to libtcod, but aiming to be Rust-native.

## 官网

- 官网：https://github.com/thebracket/bracket-lib
- crates.io 页面：https://crates.io/crates/rltk
- 源码仓库：https://github.com/thebracket/bracket-lib
