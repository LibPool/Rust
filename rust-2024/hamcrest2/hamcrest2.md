# hamcrest2

> 标签: Rust

## 简介

A port of the Hamcrest testing library. Fork of original
hamcrest-rust (which is unmaintained) with extra matchers, better docs etc.

## 官网

- crates.io 页面：https://crates.io/crates/hamcrest2
- 文档：https://docs.rs/hamcrest2
