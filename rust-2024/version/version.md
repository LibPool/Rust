# version

> 标签: Rust

## 简介

A very simple library who's job is to return the version of your crate if you're building with Cargo.

## 官网

- crates.io 页面：https://crates.io/crates/version
- 源码仓库：https://github.com/nulldatamap/version

## 获取地址

- Cargo 安装：`cargo add version`
