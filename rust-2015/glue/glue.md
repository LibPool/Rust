# glue

> 标签: Rust

## 简介

Glue is a parser combinator framework for parsing text based formats, it is easy to use and relatively fast too.

## 官网

- crates.io 页面：https://crates.io/crates/glue
- 源码仓库：https://gitlab.com/glue-for-rust/glue-rs
