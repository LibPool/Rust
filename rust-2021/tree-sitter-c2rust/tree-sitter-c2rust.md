# tree-sitter-c2rust

> 标签: Rust

## 简介

Rust bindings to the Tree-sitter parsing library, with a pure Rust runtime via c2rust

- 官网：https://tree-sitter.github.io/tree-sitter
- crates.io 页面：https://crates.io/crates/tree-sitter-c2rust
