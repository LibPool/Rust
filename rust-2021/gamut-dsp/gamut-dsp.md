# gamut-dsp

> 标签: Rust

## 简介

Shared fixed-point DSP kernels for the gamut codecs: bit-exact AV1 transform kernels (DCT/ADST/identity/WHT), cross-codec integer rounding/clamp math, and µ-law companding.
