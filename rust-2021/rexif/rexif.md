# rexif

> 标签: Rust

## 简介

RExif is a native Rust crate, written to extract EXIF data from JPEG and TIFF images.

## 官网

- 官网：https://lib.rs/crates/rexif
- crates.io 页面：https://crates.io/crates/rexif
- 文档：https://docs.rs/rexif
- 源码仓库：https://github.com/kornelski/rexif.git
