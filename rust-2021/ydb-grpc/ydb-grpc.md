# ydb-grpc

> 标签: Rust

## 简介

Crate contains generated low-level grpc code from YDB API protobuf, used as base for ydb crate

## 官网

- crates.io 页面：https://crates.io/crates/ydb-grpc
- 源码仓库：https://github.com/ydb-platform/ydb-rs-sdk/tree/master/ydb-grpc
