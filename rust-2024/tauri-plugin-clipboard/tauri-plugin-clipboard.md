# tauri-plugin-clipboard

> 标签: Rust

## 简介

A clipboard plugin for Tauri that supports text, html, rtf, files and image, as well as clipboard update listening.

## 官网

- crates.io 页面：https://crates.io/crates/tauri-plugin-clipboard
- 源码仓库：https://github.com/CrossCopy/tauri-plugin-clipboard
