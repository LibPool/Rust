# git2version

> 标签: Rust

## 简介

This crate provides a way to get the version of the package from git and incorporate it as a constant into your program.

## 官网

- crates.io 页面：https://crates.io/crates/git2version
- 文档：https://docs.rs/git2version
- 源码仓库：https://github.com/smessmer/git2version
