# dbus-tokio

> 标签: Rust

## 简介

Makes it possible to use Tokio with D-Bus, which is a bus commonly used on Linux for inter-process communication.

## 官网

- crates.io 页面：https://crates.io/crates/dbus-tokio
- 文档：http://docs.rs/dbus-tokio
- 源码仓库：https://github.com/diwic/dbus-rs
