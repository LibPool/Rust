# i2cdev

> 标签: Rust

## 简介

Provides API for safe access to Linux i2c device interface.

- 官网：https://github.com/rust-embedded/rust-i2cdev
- crates.io 页面：https://crates.io/crates/i2cdev
- 文档：https://docs.rs/i2cdev
- 源码仓库：https://github.com/rust-embedded/rust-i2cdev
