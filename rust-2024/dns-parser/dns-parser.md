# dns-parser

> 标签: Rust

## 简介

Pure-rust DNS protocol parser library. This does not support network, only
    raw protocol parser.

## 官网

- 官网：https://github.com/tailhook/dns-parser
- crates.io 页面：https://crates.io/crates/dns-parser
