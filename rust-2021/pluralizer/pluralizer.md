# pluralizer

> 标签: Rust

## 简介

Rust package to pluralize or singularize any word based on a count inspired on pluralize NPM package

- crates.io 页面：https://crates.io/crates/pluralizer
- 文档：https://docs.rs/pluralizer
- 源码仓库：https://github.com/KennethGomez/pluralizer
