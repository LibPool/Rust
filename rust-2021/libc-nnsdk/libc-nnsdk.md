# libc-nnsdk

> 标签: Rust

## 简介

Rust bindings for the parts of libc exposed by nnsdk, intended to be a in-place replacement for standard Rust libc bindings

## 官网

- crates.io 页面：https://crates.io/crates/libc-nnsdk
- 文档：https://docs.rs/libc-nnsdk
- 源码仓库：https://github.com/ultimate-research/libc-nnsdk
