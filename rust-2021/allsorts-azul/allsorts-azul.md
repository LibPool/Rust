# allsorts-azul

> 标签: Rust

## 简介

Azul's fork of the allsorts font parser / shaping engine / subsetter. Adds pixel-snap hinting fixes, slimmer direct dependencies (7 fewer than upstream), zero-copy shared `glyf` storage, + assorted bug fixes to YesLogic's upstream. Intended to be upstreamed — use the official `allsorts` crate if you can.
