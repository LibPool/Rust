# esp-wifi

> 标签: Rust

## 简介

A WiFi, Bluetooth and ESP-NOW driver for use with Espressif chips and bare-metal Rust

## 官网

- crates.io 页面：https://crates.io/crates/esp-wifi
- 文档：https://docs.espressif.com/projects/rust/esp-wifi/latest/
- 源码仓库：https://github.com/esp-rs/esp-hal
