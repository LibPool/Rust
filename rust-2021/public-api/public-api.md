# public-api

> 标签: Rust

## 简介

List and diff the public API of Rust library crates. Relies on rustdoc JSON output from the nightly toolchain.

## 官网

- crates.io 页面：https://crates.io/crates/public-api
- 文档：https://docs.rs/public-api
- 源码仓库：https://github.com/cargo-public-api/cargo-public-api/tree/main/public-api
