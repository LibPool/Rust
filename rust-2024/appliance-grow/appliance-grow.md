# appliance-grow

> 标签: Rust

## 简介

The runtime data-set growth every nordisk appliance runs the same way: a phase machine (draining → unmounted → waiting-members → growing → mounting → done|failed) over a World seam a product implements, 'unmounted' said only once the set is OFF, a drain that holds every twin to a barrier (and a twin that answers NoStandby), the signed go-ahead with its spent-nonce ledger, the boot stack's grow-journal reader, the capacity ladder (unknown / sealed / operator-only / at-restart / at-runtime) and the probes it decides over (/proc/mounts + md sysfs, PCI hot-plug). Feature `md` adds the volume half over korp-installer's grow engine (umount, the guard tmpfs, md stop, rescan, survey, G1–G6 + mount, the journal).
