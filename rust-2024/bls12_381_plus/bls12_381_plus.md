# bls12_381_plus

> 标签: Rust

## 简介

Implementation of the BLS12-381 pairing-friendly elliptic curve construction.
This is a fork of zkcrypto/bls12_381 that adds hash-to-curve and multi-exponentiation methods
and enables multi-pairing without requiring an allocator.
