# jsonpath_lib

> 标签: Rust

## 简介

It is JsonPath engine written in Rust. it provide a similar API interface in Webassembly and Javascript too. - Webassembly Demo: https://freestrings.github.io/jsonpath

## 官网

- crates.io 页面：https://crates.io/crates/jsonpath_lib
- 文档：https://docs.rs/jsonpath_lib/0.3.0/jsonpath_lib
- 源码仓库：https://github.com/freestrings/jsonpath
