# which

> 标签: Rust

## 简介

A Rust equivalent of Unix command "which". Locate installed executable in cross platforms.

- crates.io 页面：https://crates.io/crates/which
- 文档：https://docs.rs/which/
- 源码仓库：https://github.com/harryfei/which-rs.git
