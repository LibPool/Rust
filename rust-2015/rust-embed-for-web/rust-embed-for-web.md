# rust-embed-for-web

> 标签: Rust

## 简介

Rust Macro which embeds files into your executable. A fork of `rust-embed` with a focus on usage on web servers.

## 官网

- crates.io 页面：https://crates.io/crates/rust-embed-for-web
- 文档：https://docs.rs/rust-embed-for-web
- 源码仓库：https://github.com/SeriousBug/rust-embed-for-web
