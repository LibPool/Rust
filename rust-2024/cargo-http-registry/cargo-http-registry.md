# cargo-http-registry

> 标签: Rust

## 简介

A cargo registry allowing for quick publishing of crates when using
crates.io is just not desired.

## 官网

- 官网：https://github.com/d-e-s-o/cargo-http-registry
- crates.io 页面：https://crates.io/crates/cargo-http-registry
